🔑 Add your API key first

  1. In the project folder, copy .env.example and name the copy .env.
  2. Open .env in a text editor and paste your key after GEMINI_API_KEY= – no quotes, no spaces.
  3. Save the file and click (no server restart needed).

Never paste the key into this chat or into code that goes to GitHub. .env is excluded by .gitignore.
